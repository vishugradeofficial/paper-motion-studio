# Paper Motion Studio

Read SKILL.md before producing a reel. Keep secrets in a local ignored .env; new generation consumes credits. Reference media stays outside the repository. Do not copy the reference creator's branding, avatar, script or soundtrack.

Run Python helpers from this repository root. Run `npm --prefix studio run typecheck` and `python scripts/test_pipeline.py` after pipeline changes. Render and inspect a current storyboard before video. Final videos belong in out/ and reviewable example exports in examples/.

Use short, warm, natural speech with purposeful silent beats. Do not speed or stretch speech to fill a fixed runtime. For a tutorial, show a real example and a concrete viewer action. Do not present illustrative bars as measured performance data.
